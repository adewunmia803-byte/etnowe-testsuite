## BUG-001: Merchant Location Not Updating After Selection

**Module:** Merchant Management  
**Priority:** High  

### Description:
When editing a merchant’s location and selecting a new value from the dropdown, the selected location does not reflect or save on the UI.

### Steps to Reproduce:
1. Open merchant profile page  
2. Click on **Edit Location**  
3. Select a new location from the dropdown  
4. Click Save  
5. Refresh the page  

### Expected Result:
Selected location should be saved and displayed correctly.

### Actual Result:
Location remains unchanged after saving or refresh.

### Test Case:
**TC-001: Verify merchant location update functionality**

- **Precondition:** Merchant profile exists  
- **Steps:**
  1. Navigate to merchant profile
  2. Click Edit Location
  3. Select a valid location
  4. Save changes
  5. Refresh page
- **Expected Result:** Updated location should persist after refresh

## BUG-003: Inventory Items Not Fully Synced During Onboarding

1. Complete onboarding process

### Expected Result:
All 40 items should be successfully transferred to store inventory.

Only 20 items appear in store inventory; 20 remain pending.

### Test Case:
**TC-003: Verify complete inventory sync during onboarding**

- **Precondition:** Master inventory contains 40 items  
- **Steps:**
  1. Start onboarding process
  2. Complete inventory sync
  3. Open store inventory tab
- **Expected Result:** All 40 items should be present
